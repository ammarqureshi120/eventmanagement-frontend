# eventhub-frontend

React single-page app for EventHub (Vite, React 19, TypeScript 6, Tailwind 4, shadcn/ui on Radix).

This repo is one of three, cloned side by side under the `eventhub-docs` workspace root:

```text
eventhub/            # eventhub-docs (planning docs, git-ignores the two code repos)
  backend/           # eventhub-backend  (API + Aspire AppHost; owns openapi/openapi.json)
  frontend/          # eventhub-frontend (this repo)
```

## Run locally

The normal way is through the backend's Aspire AppHost, which wires the local SQL Server and starts Mailpit, the API and this Vite dev
server together:

```powershell
npm ci                                   # once, in frontend/
cd ../backend
dotnet run --project src/EventHub.AppHost
```

Open the `web` resource URL from the Aspire dashboard. The browser only calls this origin; Vite proxies `/api` to the API
using the endpoint Aspire injects (`services__api__https__0` / `services__api__http__0`). No CORS.

Frontend only (no API): `npm run dev` (proxy falls back to `http://localhost:5139`).

## Scripts

| Script | What it does |
| --- | --- |
| `npm run lint` | ESLint 10 + `eslint-plugin-boundaries` (feature-sliced layer rules, AD-2) |
| `npm run typecheck` | `tsc -b` (TypeScript 6.0.3) |
| `npm run test` | Vitest 5 in `TZ=UTC` with MSW |
| `npm run build` | Type-check + production build |
| `npm run e2e` | Playwright smoke on the `DEVICE_MATRIX` (6 devices x light/dark) with axe; serves `dist/`, so build first |
| `npm run api:generate` | Regenerates `src/api/generated/<tag>.ts` from `../backend/openapi/openapi.json` |
| `npm run api:check` | Regenerates, then fails if the result differs from what git tracks |
| `npm run audit` | `npm audit` |
| `npm run ci` | The single CI entry point: lint, typecheck, codegen drift, test, build, e2e, audit |

First-time Playwright setup: `npx playwright install chromium webkit`.

## Contract rules (AD-4)

- `src/api/generated/*` is generated by `@rtk-query/codegen-openapi` and committed. Never edit it by hand; on a merge
  conflict, rebase and regenerate.
- Consume only endpoints present in `eventhub-backend` `main`'s `openapi.json`. When the backend contract changes, pull
  the backend repo, run `npm run api:generate`, commit.
- Every server call goes through RTK Query (`src/shared/api/base-api.ts`: `credentials: 'include'`, `X-XSRF-TOKEN` on
  unsafe verbs).

## Theme and CSP (AD-23)

- Light / Dark / System is stored in `localStorage['eventhub-theme']` (`light` | `dark` | `system`; anything else or
  blocked storage means `system`). An inline script in `index.html` applies it before first paint; keep it inline,
  tiny and import-free (rules mirror `src/shared/theme/theme-storage.ts`).
- `npm run build` writes `dist/csp-hashes.json` (`{ "script-src": ["'sha256-…'"] }`) with the hash of that inline
  script. The static host / reverse proxy must send `script-src 'self' <that hash>` in its CSP; re-read the file
  after every build, since any edit to the script changes the hash.
- Fonts (Inter, Nunito Sans) are self-hosted via `@fontsource`; the body font is preloaded. No font or script CDN.
- Colours come only from `src/styles/tokens.css`; `tests/no-raw-colors.test.ts` and `tests/token-contrast.test.ts`
  fail `npm test` (and so `npm run ci`) on raw colours or contrast regressions.

## Layout (AD-2)

| Path | Holds |
| --- | --- |
| `src/app` | Store, router, providers, cross-feature routes, `api-enhance.ts`, `feature-deps.md` |
| `src/features/<feature>` | One PRD feature; other features import it only via its `index.ts` |
| `src/shared/{ui,api,lib,auth,theme}` | shadcn UI kit, base API, helpers; never imports features or app |
| `src/api/generated` | RTK Query endpoints + types from the OpenAPI contract |
| `src/styles/tokens.css` | Nordic Fog design tokens (the only file allowed to hold raw colours) |
| `e2e/` | Playwright specs |

shadcn primitives: **Radix** (`shadcn init -t vite -b radix -p nova`, CLI 4.21.0). Add components with
`npx shadcn@4.21.0 add <name>`; they land in `src/shared/ui`.
